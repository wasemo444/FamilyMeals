## Tier 1 — Shared Domain & Contracts

### `IContentDataService`

| | |
|-|-|
| **File** | `Shared/Services/IContentDataService.cs` |
| **Role** | Central façade for all content data reads and mutations |
| **Implementations** | `ContentDataService` (Api), `ApiContentDataService` (Client) |
| **Events** | `DataChanged` — UI refresh signal |

**Call chain (create category):**  
`Home.CreateCategoryAsync` → `ApiContentDataService.AddCategoryAsync` → `CategoryEndpoints` POST → `ContentDataService.AddCategoryAsync` → `EfAppDataStore.SaveAsync`

**Invariants:** Interface methods assume caller is authenticated. Client impl reloads bootstrap after mutations.

---

### `ContentDataService`

| | |
|-|-|
| **File** | `Shared/Services/ContentDataService.cs` |
| **Lifetime** | Scoped (Api only) |
| **Depends on** | `IAppDataStore`, `ICurrentUserContext`, `IOwnershipAuthorization` |

**Behavior:**

- Holds in-memory `_data` for the request scope
- `RunMaintenanceAsync` migrates legacy shapes and purges expired archives before persist
- Archive category cascades soft-delete to active links in same category
- `AddLinkAsync` stamps link ownership from parent category
- Unauthorized mutate in archive/restore returns `false`; toggle throws (endpoint catches → 404)

---

### `ApiContentDataService`

| | |
|-|-|
| **File** | `Shared/Services/ApiContentDataService.cs` |
| **Lifetime** | Scoped (Client) |
| **Depends on** | `IHttpClientFactory` (`"LinkNestApi"`) |

**Behavior:**

- Caches `AppData` in `_cache`; `InitializeAsync` idempotent
- After mutations: `ReloadFromServerAsync` + `DataChanged`
- `Unauthorized` event fired on 401 → `InteractiveShell` redirects to login
- Treats **403 and 404** as missing resource on archive/restore/add-link paths
- Maps HTTP 409 → `ConcurrencyConflictException`
- `RunMaintenanceAsync` is no-op (server handles maintenance)

### `ContentDataQueries`

| | |
|-|-|
| **File** | `Shared/Services/ContentDataQueries.cs` |
| **Role** | Pure static queries over in-memory `AppData` |

**Key methods:**

### `IAppDataStore` / `EfAppDataStore`

| | |
|-|-|
| **Port** | `Shared/Services/IAppDataStore.cs` |
| **Adapter** | `Api/Data/EfAppDataStore.cs` |

**Load:** Returns categories/links where `(OwnerUserId = me) OR (OwnerGroupId ∈ my groups)`. Enriches group names on categories.

**Save:**

- Syncs incoming `AppData` snapshot with DB (add/update/delete)
- New entities: validates create owner, stamps ownership (user or group from model)
- Updates: requires `RowVersion`; increments token on success
- Deletes: only if `CanMutateEntity`
- Link `CategoryId` change → **realigns link ownership** from target category
- Foreign `OwnerUserId` on create → stamped to current user
- Skips unauthorized entities silently on delete/update

**Edge cases:**

- InMemory provider: no transaction wrapper
- Stale `RowVersion` → `ConcurrencyConflictException`
- Empty `RowVersion` on update → `ConcurrencyConflictException` with explicit message

## Edge Case Checklist

| Scenario | Expected Behavior |
|----------|-------------------|
| Outsider archives group category | 404 |
| Create group category without membership | 404 |
| Invite unregistered email | 400 `invitee_not_found` |
| Invite unconfirmed email | 400 `invitee_email_unconfirmed` |
| Invite user already a member of target group | 400 on duplicate accept |
| Create second group while member elsewhere | Allowed (multi-group) |
| Accept invite when group at cap | 400 "group is full (10/10)" |
| Admin removes member | Member loses access; group content remains |
| Member leaves group | Content stays with group (orphaning default) |
| MAUI logout | Clears SecureStorage only; JWT valid until expiry |
| MAUI 401 mid-session | `UnauthorizedSessionHandler` clears token; redirect login |
| API down during token restore | Anonymous UI; token retained for retry |
| `ownerType=Group` missing `ownerGroupId` | 400 |
| Duplicate name in same owner scope | 409 on create / `IsCategoryNameTaken` true |
| Duplicate name across personal vs group | Allowed |
| Move link to group category | Link ownership updated to group |
| Stale RowVersion on save | 409 |
| Unauthenticated bootstrap | 401 |
| Logout from external site form | 400 (origin check) |
| Link preview to private IP | Blocked by `SafeUrlValidator` / `ISafeUrlFetcher` |
| Orphan legacy rows at startup | Backfilled by `OwnershipBackfillService` |

When modifying a Tier 1–3 class:

1. Update the type's `///` XML comments in source
2. Adjust the matching section in this file if responsibilities changed
3. Update [L2.md](L2.md) if cross-cutting flows changed
4. Update [agents.md](agents.md) non-negotiables if new invariants emerge
