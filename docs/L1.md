## Purpose

LinkNest helps people **save, organize, and share links** to any online content — videos, courses, articles, recipes, and more. Users create **categories**, add **links** with optional titles and notes, favorite items, archive old content, and filter a unified home view across personal and group-owned data.

Primary capabilities today:

- Email/password authentication with ASP.NET Identity
- Personal and **group-owned** categories and links (E3/E4)
- **Group membership management** — email invites, accept/decline, member list, admin remove, self leave (E5)
- Unified home with All / Mine / Shared filters
- PWA share-target flow (`/share`) to save links from other apps
- English and Arabic UI with RTL support
- Soft archive with 7-day retention before purge

### Main URL Entry Points

| URL | Purpose |
|-----|---------|
| `/` | Home — categories, filters, create category/group |
| `/groups` | Groups — list, create, pending invites |
| `/group/{id}` | Group members — list, invite (admin), remove (admin), leave |

## Project Responsibilities

### LinkNest.Shared

Cross-cutting **contracts and pure logic** referenced by Api, Web, and Client.

| Namespace / folder | Owns |
|--------------------|------|
| `Models/` | `ContentCategory`, `SavedLink`, `AppData`, `ContentOwner`, `GroupSummary` |
| `Services/` | `IContentDataService`, `ContentDataQueries`, `OwnershipRules`, HTTP clients |
| `Auth/` | Login/register DTOs, `AuthNavigation` |
| `Resources/` | `LocalizationCatalog` (EN/AR strings) |
| `Constants/` | `ArchivePolicy`, `WellKnownUsers` |

### LinkNest.Api

**System of record.** All content data mutations persist here.

| Area | Owns |
|------|------|
| `Endpoints/` | REST surface (`CategoryEndpoints`, `LinkEndpoints`, `GroupEndpoints`, …) |
| `Data/` | EF Core `AppDbContext`, entities, migrations, `EfAppDataStore` |
| `Services/` | Ownership authorization, link preview, archive maintenance, backfill |
| `Identity/` | User seeding, cookie configuration, email confirmation |
| `Middleware/` | Pre-load content data; map concurrency conflicts to 409 |

### LinkNest.Web

**Browser host** — not the data API, but shares Identity/DbContext for form login.

| Area | Owns |
|------|------|
| `Endpoints/AccountEndpoints` | HTML form login/logout |
| `ReverseProxy/` | Forward `/api/*` to Api with auth cookie |
| `Auth/` | SSR↔WASM auth state bridge |
| `Components/` | App shell, routing, layout |

### LinkNest.Mobile (E7)

**MAUI Blazor Hybrid** — reuses Web.Client pages today; calls Api directly with JWT.

| Area | Owns |
|------|------|
| `MauiProgram.cs` | DI, appsettings, BlazorWebView |
| `Services/MauiSecureTokenStore.cs` | JWT in platform SecureStorage |
| `MobileServiceCollectionExtensions.cs` | Bearer auth + HTTP handlers |
| `Components/Routes.razor` | Routes Web.Client/UI assembly pages |

Deferred: Android TFM (E9 H3), extract UI to `LinkNest.UI` (E9 H4). See [E9 ticket](tickets/E9-carry-over-from-previous-epic.md#e7-mobile--deferred-follow-ups-carry-over-from-architect-review).

### LinkNest.Web.Client

**Interactive UI** loaded into the Web host.

| Area | Owns |
|------|------|
| `Pages/` | Home, Category, Share, Archive, Groups, GroupMembers, Login, Register, Settings, ForgotPassword, ResetPassword |
| `Components/` | `InteractiveShell`, `CategoryCard`, `LinkCard` |
| `Services/` | `CultureService`, `LinkPreviewClient` |

## Primary User Flow (Happy Path)

1. User logs in via **HTML form** → `POST /account/login` (Web) → auth cookie set on Web origin.
2. `InteractiveShell` loads → `ApiContentDataService.InitializeAsync()` → `GET /api/bootstrap` (via proxy, cookie forwarded).
3. User creates a category on Home → `POST /api/categories` → server persists via `ContentDataService` → client reloads bootstrap.
4. User opens category → adds links → preview fetched server-side via `/api/link-preview`.
5. User logs out → `POST /account/logout` (same-origin validated) → redirect to `/login`.

## Configuration Essentials

| Key | Purpose |
|-----|---------|
| `ConnectionStrings:DefaultConnection` | PostgreSQL connection (Api + Web). Neon `postgresql://` URIs are converted automatically. |
| `ReverseProxy:ApiBaseAddress` | Api URL for YARP (Web) |
| `DataProtection:KeysPath` | Shared key ring for Identity cookies |
| `IdentitySeed:*` | Default dev user seed |
| `Auth:RequireConfirmedEmail` | Gate sign-in until email confirmed |
| `Auth:WebBaseUrl` | Public web URL for confirmation/reset email links (API) |
| `Email:UseSmtp` | When `true`, send via SMTP in Development (default: log to console) |
| `Email:Smtp:*` | Brevo/host SMTP settings (API only) |
